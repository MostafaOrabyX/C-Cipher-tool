# C Cipher_tool 

## Description

A simple CLI cipher_tool that allow the user to encrypt or decrypt any text .

---

## features 

* Allows user to encrypt a plaintext
* Allows user to decrypt a ciphertext
* Handles invalid user input
* Runs in a loop until the user exit

---

## How to Run

1. Compile the code
2. Run the program

## Example

Enter the first letter  
Encrypt(E) or Decrypt(D):e  
Text: Hello, world  
Code: 7  
Ciphertext: OLSSV, DVYSK  
Do you want to encrypt or decrypt anything else (y/n):n
